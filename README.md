# MusicPlayer — Privacy Policy

Dépôt **public** dédié à l'hébergement de la politique de confidentialité de l'application
Android **MusicPlayer**, via GitHub Pages.

Ce dépôt doit rester **public** pour que l'URL reste accessible en permanence (exigée par
Google AdMob et le Google Play Store), indépendamment du dépôt de code de l'application.

- Page : [`index.html`](index.html)
- URL publique (après activation de GitHub Pages) :
  `https://rodolphe18.github.io/musicplayer-privacy/`
